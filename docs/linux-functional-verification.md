# Linux functional repair verification

13 October 2026, Reflow 0.4.0, Ubuntu 26.04.1 LTS / KDE Plasma 6.6.6 / Wayland. This report supersedes earlier statements that Linux implementation was complete. **The complete native recording-to-visible-insertion workflow remains unverified.** No successful browser/editor/Konsole dictation is claimed.

## Reproduced blockers and repairs

The starting worktree contained extensive uncommitted changes; these were retained. No AGENTS.md was found in the checkout or its ancestor directories. No reset, stash, commit, tag, system-wide installation, upload, or publication was performed. Saved model, language, precision, input, clipboard, privacy, and startup preferences were retained. A 5.1 GiB user-local speech environment was created at `~/.local/share/reflow/python-runtime` from the existing dependency installation, with no downloads. The checkout environment was retained.

1. **Release interpreter discovery:** A normal release launch, without an activated shell, selected `/usr/bin/python3` and failed before recording admission because NumPy was absent. Previous backend checks used `.venv` and missed this release behavior. Discovery now recognizes a checkout from the executable's actual location, including release binaries, rather than a compiled-in build-machine path. Installed launches support an additive saved `asr.python_path` and an environment at `reflow/python-runtime`. `REFLOW_PYTHON` remains authoritative. Model settings offer Apply and reload; Linux system-Python errors explain isolated environment setup. Home distinguishes installation, loading, and runtime errors.
2. **Wayland release discarded speech:** Portal `Deactivated` called the binding's cancellation callback; that dispatcher discards the recording. It now calls release, which transcribes and delivers. Repeats are suppressed, and release uses the mode remembered at key-down. Revocation/rebinding still cancels owned recordings. Regression coverage exercises 30 callback sequences, toggle repeats, duplicate release, and a mode change while held. This verifies callback routing, not physical shortcut delivery. The [portal signal contract](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.GlobalShortcuts.html) was checked.
3. **System-default input was a playback monitor:** `pactl get-default-source` reported `alsa_output.pci-0000_01_00.1.pro-output-3.monitor`. Generic ALSA default capture could receive playback or silence. An unspecified Linux microphone now resolves the actual PipeWire default input; when the default is a monitor, it resolves a physical microphone. If PipeWire reports only playback monitors, recording returns an actionable missing-microphone error. ALSA-only systems retain their fallback when `pactl` is unavailable. Explicit input and monitor selections retain their behavior. Controlled capture now selects a microphone at each session boundary.
4. **Browser clipboard blocked insertion:** The actual clipboard offered HTML, plain text aliases, and Chromium metadata. The previous arboard snapshot refused these formats. Wayland snapshots now retain exact MIME payloads, within 64 MiB / 64 formats, with bounded payload-pipe reads. Private password hints and cut-file selections still refuse replacement. A temporary offer marker cancels restoration after a new same-text or richer copy. Missing ownership proof also cancels restoration. Native Copy IPC makes manual delivery independent of WebKit's browser Clipboard API. The actual browser offer was read and preserved without modifying the selection; live write/restore remains pending.
5. **AppImage launcher broke host Python and native Wayland:** The packaged launcher set `PYTHONHOME` to its own `usr` directory, which has no Python standard library. A saved interpreter consequently failed with `ModuleNotFoundError: encodings`. Its GTK hook also unconditionally forced X11. AppImage hooks preserve explicit caller settings and allow GTK to choose the session; host workers recover caller Python/library settings and discard bundle-specific paths. Media framework bundling addresses the observed missing GStreamer appsink. The [Tauri AppImage configuration](https://v2.tauri.app/reference/config/#appimageconfig) was checked. Final image launch results are recorded below.

Revocation now signals a processing session immediately instead of waiting behind its stop pipeline. Cancellation propagates into an already-running delivery worker and queued Wayland input, so dropping the async session prevents subsequent key presses. Regression tests cover these boundaries. Additional repairs close pending portal consent requests on cancellation/timeouts, rotate consumed keyboard restore tokens even when no replacement is returned, gate version-2 shortcut configuration, and report HUD support only after GTK confirms a layer window. Session diagnostics record identifiers, energy, recognition length, and delivery dispatch without logging private transcript text. Existing IPC and Windows/X11 paths remain present.

## Environment and methods

Ryzen 5 7535HS; RTX 2050 with 4 GiB VRAM; NVIDIA 595.99.02; Python 3.14.4; Torch 2.13.0+cu130. PipeWire and desktop portals were active. The existing selected model was Zipformer 20M CPU INT8, with auto language; this is an English-only model and is not evidence of Hindi support. External clipboard/input command-line tools remained unavailable; the application uses its native integrations.

Native computer-use initialization timed out once, then returned an empty native-app inventory and a Chrome request-header-policy error. `cua.listWindows` was unavailable. No alternative screenshot, click, key synthesis, or native UI automation was substituted. A user-assisted native dictation check was requested; no outcome was supplied. Backend and package tests were continued independently.

Package launches use `/tmp` as the working directory, a minimal inherited desktop environment, an isolated XDG data directory, and automatic discovery of the user-local speech environment. An earlier pass also verified saved interpreter paths. They preload the same installed Zipformer weights. These test configurations disable network access, API serving, autostart, and retention; user settings are untouched. Native model-ready logs prove subprocess/runtime readiness, not that the window is visually usable. Harness termination is forced and does not verify tray Quit. Owned AppImage process groups are cleaned up.

## Automated checks and measurements

Final check counts and artifact hashes are recorded in `linux-functional-results.json`. Passed checks: frontend lint, formatting, TypeScript, 240 frontend tests, production build; Rust fmt/Clippy with warnings denied and 847 passing Rust tests (18 environment-dependent tests ignored by default); Python selftest and 37 regressions; 11 benchmark/path and three protocol regressions; 19 Node checks with two Windows-only skips. Native-only tests are explicitly separated.

The 6.625-second English fixture SHA-256 is `6bc58a4efdf20daac252b6b1502632601a71efe0308f6757dc1eda34891a7e4f`. Reference: “After early nightfall the yellow lamps would light up, here and there, the squalid quarter of the brothels.” Twenty warm repetitions measured median/p95 full offline recognition **167.21 / 178.19 ms**, final drain **7.26 / 7.89 ms**. New-process loading with warm filesystem caches took 6.33 s. WER was 5.56%, CER 3.45%; the existing strict accuracy gate was not relaxed. These measurements do not justify a speedup or new model/precision recommendation. They exclude capture playback duration, cleanup, insertion, and visible target text.

Detailed logs and extracted packages are in `/tmp/reflow-functional/`; these temporary paths may disappear. Durable measurements and artifact hashes are retained in the results JSON.

Clipboard payload-pipe reads have a deadline, but compositor offer negotiation uses the synchronous `wl-clipboard-rs` protocol. Multi-format snapshots compare the offered MIME sets across reads; a source change that retains the same MIME set during a snapshot is not proven atomic. Native clipboard race and restoration tests remain pending.
