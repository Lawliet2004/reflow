## Procedure A

On fresh Windows x64/Linux x64, and separately Intel/Apple Silicon Mac, start with no developer environment, cache or app data. Install the packaged app, keep downloads off and confirm setup requires consent. Enable downloads, select Zipformer, finish dependencies and weights, recognize a fixed audio sample, dictate/paste into an external editor, restart and repeat offline. Inspect package inventory: no torch/transformers in Zipformer environment. Record package build, OS, architecture, filesystem, timings and failures. Source builds separately require documented Node/Rust/system libraries.

## Procedure B

For supported NVIDIA generations/drivers, test fresh install, warm reload and CPU/GPU/Auto changes after readiness and during an active session. Record actual loaded device and adapter, not just UI selection. Run recognition, fill/free VRAM with another process, test multiple GPUs and CUDA_VISIBLE_DEVICES remapping, and force a launch failure. GPU only must fail visibly when unsatisfied. Auto CPU fallback must pass live host RAM admission. Confirm explicit CPU setup installs no CUDA package variant. Separately measure Intel/AMD/Mac CPU performance; do not claim MPS/AMD support.

## Procedure C

Use VM/physical OS boundaries for Windows 10+, Intel Mac 10.15+, Apple Silicon macOS 14+, glibc 2.27 Zipformer/2.28 heavy profiles, and CPUs with/without AVX2. Inspect selected lock and preflight blockers before downloads. On ARM64 execute imports, model load and recognition. Musl, Windows ARM/32-bit and generic Jetson are not established targets. Confirm unsupported combinations fail with recovery guidance.

## Procedure D

In disposable app data, first establish a working generation. For archive transfer/extraction, venv creation, pip download/install, verification, pointer promotion and model-weight transfer: cancel, quit/kill, drop network, reboot, then restart/retry. Compare old generation bytes, pointer and usable interpreter before/after failure. Verify cancellation affects only the matching installer and no orphan continues traffic. Test a stalled server, body interruption, Range resume, ignored/malformed ranges and final checksum failure. Measure cancellation latency; SDK blocking reads and archive entries have documented limits. Repeat on Windows with locked/quarantined files. Never fault-inject into real app data.

## Procedure E

Use a fixed two-hour compressed fixture plus malformed codecs and a small known WAV. Record peak RSS with the model resident, compare short/long files, inspect bounded queue behavior, cancel while decoding and while inference awaits a response, and confirm no completed job appears after cancellation. Verify subtitle timestamps across segments. In isolated SQLite, inject transcript/segment/retention failures: either complete transcript+segments commit or neither; optional audio failure produces a saved result and visible warning. Confirm encrypted chunk roundtrip, retention purge and deletion cascade.

## Procedure F

Use disposable capacity-limited volumes for application data/cache and model import sources. Check combined setup+model estimate before transfers, fill storage during extraction/install/commit and confirm old generation survives. Verify pip TEMP/TMP/TMPDIR are on app cache. Repeat read-only/noexec/long Windows path and file-lock cases. Record free space at each stage; estimates include safety margin but cannot prevent concurrent external disk use.

## Procedure G

Start offline, toggle mid-transfer, block each approved host, inject 429/5xx and dropped bodies, and use a corporate TLS/auth proxy/captive portal. Confirm no unapproved redirect/index destination succeeds, certificates remain verified, inherited pip config cannot add sources, hashes are enforced and local inference remains offline. Compare traffic with the journal's host/payload entries; a force-killed in-flight tally may be absent, and protocol/proxy overhead is not included.

## Procedure H

Use copies in disposable app data. Activate a broken external VIRTUAL_ENV, test valid/broken explicit interpreter overrides, old/malformed/mismatched receipts, and delete/truncate/corrupt model files. Check readiness reflects actual selected profile and interpreter; verify/repair must recover artifacts without accepting a receipt alone. Test corrupt settings and denied backup writes; original bytes must survive. For encrypted history test missing keys/corrupt databases and retention chunks; original data must remain recoverable. Test checksum-verified offline model import with a separately installed matching runtime.

## Procedure I

On each supported desktop/audio backend, exercise permission deny/revoke, no/default/selected/USB/Bluetooth microphones, device removal/profile changes, shortcut hold/double-tap/collision and portal denial. Dictate into editor, terminal and elevated/secure apps with focus changes and busy clipboard. Check recognition and external insertion independently; Record/copy fallback must be discoverable. macOS requires separate mic/Accessibility acceptance.

## Procedure J

Use a physical phone on the same private LAN with Docker/VM/VPN adapters enabled. Check proposed addresses, manually choose another listed address, scan the resulting QR and stream. Test guest isolation, firewall denial, occupied port, listener changes and token revocation. Verify actionable listener errors, HTTPS fingerprint behavior, reconnection and Android background lifecycle. Do not weaken authentication to recover connectivity.

## Procedure K

Read the release workflow for the exact commit and run packaging/release tests without pushing a tag. On fresh machines verify installer trust/quarantine prompts with the actual signing configuration. Check all macOS artifacts remain visibly preview and README matches automatic publication of a complete tagged release. A future change to that policy needs a product decision.
